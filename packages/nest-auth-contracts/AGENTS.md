# AGENTS.md — `@ackplus/nest-auth-contracts`

> **Types only.** No runtime code. Build is `tsup`.

## What this package is

The single source of truth for shared TypeScript types across:

- `@ackplus/nest-auth` (backend)
- `@ackplus/nest-auth-client` (JS client)
- `@ackplus/nest-auth-react` (React layer)

A change here will (deliberately) break the others at compile time. **Touch this first** when adding/changing a DTO or enum.

## Public surface

Exported from `src/index.ts` (re-exports every file under `src/`):

| File | Holds |
| --- | --- |
| `auth.ts` | Login/signup credentials, token pairs, auth responses, OTP types, `INestAuthSession`, `INestAuthIdentity`, `INestAuthAccessKey` |
| `mfa.ts` | TOTP setup, 2FA verification, trusted devices, MFA status |
| `password.ts` | Forgot/reset/change password DTOs |
| `verification.ts` | Email/phone verification |
| `passwordless.ts` | Passwordless OTP / magic-link |
| `user.ts` | `INestAuthUser` |
| `role.ts` | `INestAuthRole`, `INestAuthPermission`, role/permission CRUD inputs |
| `tenant.ts` | `INestAuthTenant`, `INestAuthUserAccess` |
| `config.ts` | Public client config types (auth-method toggles, MFA, registration, SSO, UI branding) |
| `admin.ts` | Admin initialization |

## Naming conventions

- **Domain entities** → `INestAuth{Entity}` (e.g. `INestAuthUser`, `INestAuthRole`)
- **Enums** → `NestAuth{Name}Enum` (e.g. `NestAuthMFAMethodEnum`, `NestAuthOTPTypeEnum`)
- **Request DTOs** → `I{Feature}Request`
- **Response DTOs** → `I{Feature}Response`
- **Configuration** → `I{Feature}Config` or `I{Feature}Options`
- **Constants** → `NEST_AUTH_{NAME}` (e.g. `NEST_AUTH_PASSWORDLESS_PROVIDER`)

## When you change a type

1. **Update here first.** Bump the file in `src/`.
2. `pnpm build` — verify nothing in this package errors.
3. Build dependents in order: `pnpm -C packages/nest-auth build`, then the clients.
4. Compile breaks in the dependents are intentional — they tell you exactly what code needs updating in the consuming layer.

## Things that look like runtime but aren't

`NEST_AUTH_PASSWORDLESS_PROVIDER` is a `const` string — it's the only runtime export and it's literally a string literal. Don't add classes, factories, or anything with side effects here.

## Build

`tsup` produces `dist/index.cjs` (CommonJS), `dist/index.js` (ESM), `dist/index.d.ts` (types). Configured in `tsup.config.ts`. Don't add JS sources to `src/`.
