Nest Auth is an authentication suite for NestJS backends and any JavaScript or React frontend. It ships everything you need for production auth — sessions, MFA, OAuth, passwordless, multi-tenancy, RBAC, audit logging, an embedded admin console — and gets out of your way for everything else.

## Start here

Three steps from zero to a working integration:

1. **Install** — add the backend module and a frontend SDK. See [Installation](/docs/getting-started/installation).
2. **Core Concepts** — sessions, tokens, MFA, RBAC, and multi-tenancy in 10 minutes. See [Core Concepts](/docs/concepts).
3. **Pick your SDK** — wire up the client for your platform from the quick-jump grid below.

> **New to Nest Auth?** Read the [Introduction](/docs/introduction) first — what it is and why it exists.

## Pick your SDK

| Package | Use it for | Docs |
|---|---|---|
| [`@ackplus/nest-auth`](/docs/backend) | NestJS module — auth flows, guards, decorators, MFA, sessions, RBAC, multi-tenancy | [Backend](/docs/backend) |
| [`@ackplus/nest-auth-client`](/docs/client) | Framework-agnostic JS/TS auth client | [JS Client](/docs/client) |
| [`@ackplus/nest-auth-react`](/docs/react) | React provider, hooks, guards, Next.js helpers | [React](/docs/react) |
| [`@ackplus/nest-auth-react-native`](/docs/react-native) | React Native / Expo apps | [React Native](/docs/react-native) |
| [`nest_auth_flutter`](/docs/flutter) | Flutter / Dart apps | [Flutter](/docs/flutter) |

`@ackplus/nest-auth-contracts` ships the shared TypeScript types consumed across every package — you rarely import it directly.
