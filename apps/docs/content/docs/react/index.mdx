React provider, hooks, guards, and Next.js helpers.

- [Provider](/docs/react/provider) — `<AuthProvider>` and `<NextAuthProvider>` props + initial-state hydration.
- [Hooks](/docs/react/hooks) — `useNestAuth`, `useUser`, `useSession`, `useAccessToken`, `useAuthStatus`, `useHasRole`, `useHasPermission`.
- [Guards](/docs/react/guards) — `<AuthGuard>`, `<GuestGuard>`, `<RequireRole>`, `<RequirePermission>` + HOC variants.
- [Next.js](/docs/react/nextjs) — `createNextAuthHelpers`, `getServerAuth`, `withAuth`, App-Router SSR pattern.
- [Cross-Tab Sync](/docs/react/cross-tab-sync) — `CrossTabSync` for multi-tab logout/login propagation.
