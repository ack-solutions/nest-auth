This section walks you from `pnpm add` to a working signup → login → protected endpoint flow. The four pages you'll spend the most time on:

- [Installation](/docs/getting-started/installation) — what to install for backend / client / react.
- [Setup Checklist](/docs/getting-started/setup-checklist) — the boot-time wiring that catches everyone the first time (cookie-parser, CORS headers, EventEmitter, ValidationPipe, AuthExceptionFilter).
- [Database Setup](/docs/getting-started/database-setup) — three supported paths: TypeORM `synchronize`, generated migrations, or copy-paste SQL. **Read this before your first run.**
- [Environment & Secrets](/docs/getting-started/environment-and-secrets) — required env vars, secret rotation.

Then pick a quickstart based on your stack:

- [Backend (NestJS)](/docs/getting-started/quickstart-backend)
- [React SPA](/docs/getting-started/quickstart-react)
- [Next.js (App Router)](/docs/getting-started/quickstart-nextjs)
- [Vanilla JS / non-React frontend](/docs/getting-started/quickstart-vanilla)
