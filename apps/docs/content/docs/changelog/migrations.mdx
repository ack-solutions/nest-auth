## v1 → v2

The complete, verified upgrade guide lives here:

**→ [v1 → v2 migration guide](/docs/migration)**

It covers every breaking change with before/after code: the API-key rehash, token-TTL config renames, hook/SDK method renames, and the schema additions.

## Beta → beta

Beta releases follow [semver pre-release](https://semver.org/#spec-item-9) semantics. We try not to break beta-to-beta, but reserve the right when an API decision turns out wrong before stable. Any beta that contains a breaking change calls it out in the [changelog](/docs/changelog).
