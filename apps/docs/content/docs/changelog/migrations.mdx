## Beta → beta

Beta releases follow [semver pre-release](https://semver.org/#spec-item-9) semantics. We try not to break beta-to-beta, but reserve the right when an API decision turns out wrong before stable. Each beta release that contains a breaking change calls it out in the [changelog](/docs/changelog).
